### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Hand%20gestures/Eyes.png" alt="Eyes" width="25" height="25" /> &nbsp;주요 기능
- **회원가입 :**
    - 회원가입을 통해 DB에 사용자 정보를 저장합니다.

- **로그인 :**
    - 회원가입한 사용자가 로그인을 할 수 있습니다.

- **프로필 조회 :**
    - 사용자의 프로필을 조회할 수 있습니다.

- **중고거래 등록 :**
    - 사용자가 물품의 이미지를 첨부하여 중고거래를 등록할 수 있습니다.

- **중고거래 조회 :**
    - 사용자가 등록한 중고거래를 조회할 수 있습니다.
      <br>

- **채팅 기능 :**
    -  사용자 간의 채팅 기능을 도입하여 소통을 원활하게 할 예정입니다.

- **Elasticsearch :**
    -  검색 기능을 향상시키기 위해 Elasticsearch를 도입할 예정입니다.

- **Firebase cloud messaging :**
    -  사용자에게 알림을 보내기 위해 Firebase cloud messaging을 도입할 예정입니다.
